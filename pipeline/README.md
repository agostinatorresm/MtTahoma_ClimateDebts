
# pipeline

Analysis code, organised by step. The README at the project root describes the data, the requirements, the run order and the script that produces each figure and table.

- `01_data_prep/`: cleaning and preparation of the survey, climate, trait and occurrence data.
- `02_analysis/`: climatic-affinity shifts (`01_thermophilization/`) and HMSC models (`02_hmsc/`).
- `04_robustness/`: robustness of the results to the difference in understory sampling between surveys.
- `05_manuscript_figures/`: Figure 1 and Figure S1.1.
- `07_data_archive/`: export of the files archived in Dryad.
